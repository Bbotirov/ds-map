# CHANGELOG

## 0.3.0 — 2026-11-18

Проверка живым прогоном в настоящем хосте VS Code и в настоящей сессии `dsh`;
всё, что ниже, подтверждено запускающимися процессами, а не юнит-моками.

- Карта как вкладка внутри окна VS Code (`dsMap.openMap`) плюс набор команд:
  выбрать сессию, карта в браузере, скопировать снимок карты, `View: Toggle`.
- Якорь окна ищется по цепочке родителей процесса, поэтому панель догоняет окно
  терминала, а не встаёт у края экрана (`parent (Code.exe)` в логе панели).
- Панель объясняет свёрнутое окно харнеса: раньше при `minimized` она молча
  пряталась, и со стороны это выглядело как падение.
- Приватность (§12.4): мёртвые файлы порта и токена больше не остаются на диске.
  Их убирают два живых свидетеля — панель, обнаружившая молчание порта
  (`src/ui/main.ts` → `clearDeadSidecar`), и расширение, когда терминал закрыли
  без Ctrl-C (`extension/src/endpoint.ts` → `clearStaleEndpoint`). Оба сначала
  проверяют порт с токеном (`probeEndpoint`), поэтому живой сайдкар не теряет
  свои файлы.
- Лента читается по-человечески («читает README.md», а не `Read`), шапка
  показывает модель, кратность и заполнение контекста; модель называется по
  первому факту харнеса, а не молчит до `model/selection`.
- Ядро покрывает все реальные записи `session.v4.jsonl`, и ни одна сырая строка
  не уходит в метки.
- Прогон в хосте расширений стал двухцикловым и честным: фейковый харнес
  (поднятие, пристыковка, `stop`, три факта порядка за собой) и настоящий
  `dsh --profile headless` с контрольным маркером в промпте — маркер обязан не
  появиться ни в снимке webview, ни в строках лаунчера.
- Раннер научился читать то, что пишет PowerShell: `*>` даёт UTF-16LE, а
  кириллицу — через OEM-страницу консоли. БOM-detect плюс обратная таблица
  кодовой страницы; без этого проверка пристыковки молча проваливалась.
- Тесты: 18 файлов, 346 тестов; покрытие `src/core/` — 100 % строк, 89 % веток
  при пороге 80.

## 0.2.1 — 2026-11-18

- Документация по запуску приведена в соответствие с реальным поведением: панель
  живёт ровно столько, сколько харнес, поэтому `--profile headless` закрывается
  сразу за ответом, а для долгой панели нужен `web`/`acp`.
- Добавлен раздел «если панель не появилась»: `dsmap doctor` как первый шаг и
  разбор единственного безобидного `✗` (файлы порта/токена после `taskkill /F`).
- Расширение: `dsMap.cliPath` и `dsMap.harnessCommand` стоит писать в User-scope —
  иначе команды работают только с открытой папкой ds-map. Текст добавлен в оба
  README; `.vsix` пересобран.

## 0.2.0 — 2026-11-18

- Иконки всех десяти станций в центре узла — геометрия перенесена из lot-map
  (`STATION_ICONS`, `ring()`), цвет по состоянию: покой / активная / ошибка /
  память со счётчиком. Подписи получили обводку цветом фона, чтобы не сливаться
  со спицами.
- Лаунчер больше не полагается на stdin EOF: панель сама следит за портом
  сайдкара (`src/ui/launcher-watch.ts`) и гасится, если лаунчер умер.
- Пристыковка к окну терминала через `GetConsoleWindow()` (якорь по HWND) плюс
  запасной вариант по заголовку терминала: Windows Terminal владеет окном
  консоли, поэтому перебор PID-дерева его не находил.
- Чтение настроек терпит BOM, который пишет PowerShell 5.1.
- Расширение VS Code (`extension/`): команды запуска/остановки/диагностики,
  индикатор в статус-баре, настройки `dsMap.cliPath` и `dsMap.harnessCommand`,
  сборка `.vsix` через `pnpm package:extension` и прогон в настоящем хосте
  расширений (`extension/test-runner/run.js`).
- LICENSE (MIT) с отметкой о происхождении геометрии из lot-map.
- Прогон расширения в хосте стал воспроизводимым: настройки возвращаются к
  `undef` в `finally`, значения перечитываются после `update()`, а `.vscode/`
  больше не влияет на следующий запуск.
- `docs/DISCOVERY.md` дополнен разделом M2–M8: живые сессии dsh и счётчики
  событий, проверка изоляции отказов (убита панель / убит сайдкар), ограничение
  доставки Ctrl-C в Windows Terminal, ловушки `vsce` под pnpm.
- Скриншоты пересняты с живыми сессиями `dsh`; README переписан по факту
  проверок.
